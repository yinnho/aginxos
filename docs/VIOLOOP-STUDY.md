# Violoop 对照研究（2026-09-01）

调研对象：[Violoop](https://www.violoop.ai/)——蓝驰领投亿元级天使+

   双重验证。

## 他们是什么（官网+报道事实）

插在现有电脑上的立方体小盒，无电源键、插电即跑，「你电脑的
第二位使用者」：HDMI 2.0 采集 4K 屏幕画面（**原始视频流不出
桌面**）+ USB-HID 操控键鼠 + 本地 Qwen 8B Q4（宣称 53 tok/s，
vs Mac mini M4 的 20）+ 云端 BYOK 路由。三个模式：

- **即时建议**：光标旁出下一步，Tab 接受，无 prompt 无聊天框
- **跨应用长任务**：交给它，它从应用到应用驱动电脑（无 API
  无插件，屏幕上有的都能用）
- **Away Mode**：派活→锁屏走人，继续干，完成或需要你时 ping 手机

三阶段自进化：**记忆**（多模态长期记忆+周期重整：合并/纠错/
重建人物-项目-事件关联，用户可见可纠可删）→ **工作流记忆**
（保存可复用方法而非点击录像：从哪取信息/冲突信什么/哪些可
提前/哪些须等确认）→ **权重蒸馏**（验证过的经验个人化后训练，
「慢思考蒸馏为快思考」——已走通全链路）。

工程含金量最高的一处——**动作路由分级表**：每个操作按「最快
可靠路径+优雅降级」执行：

| 路径 | 延迟 | 成功率 |
|---|---|---|
| SCRIPT / API | 10ms | 99% |
| 键盘快捷键 | 20ms | 95% |
| AX handle | 50ms | 90% |
| GUI 点击 | 200ms | 70% |

三个视觉模型读屏，每天在 1 万+真实软件屏幕回归测试。

安全：**双芯片隔离**——AI 芯片只准备，独立安全芯片决策；物理
确认键直连安全芯片（电气事件，AI 侧/宿主侧软件均无法伪造），
不可逆操作（发送/支付/删除/提交）必须按键。产品哲学：
「理解在生长，权力始终不动」。

## aginx-carrier 可学清单（按优先级）

### 1. 动作路由分级 → 工具/驱动层的路由元数据

carrier 的 drivers 层（crates/runtime/src/drivers）现在是「工具
能不能用」，学它变成「工具走哪条路+备胎是谁+成功率多少」：每个
能力声明首选路径与降级序（API > CLI > 浏览器兜底），每次执行的
成败落 audit.rs。**这是把我们的哲学（GUI 是最后兜底）显式立法
成数据结构**——Violoop 用三个视觉模型兜 GUI 底，我们用 agent_loop
+ 浏览器工具兜，但降级序应该是一等公民而非临时判断。

### 2. Away Mode → 「需要你」与「完成了」是两种推送

carrier 已有 cron_cmd + notify（CronAction::Push 零 LLM 推送）。
学它的状态区分：任务收尾不是单一「完成」，是三态——**done /
needs_confirm / blocked**，推送语义不同（完成=通报可略读，需要你
=等确认必须看到）。微信推送里带状态前缀即可起步，成本极低。

### 3. 不可逆操作确认闸门 → carrier 层 confirm gate

双芯片是硬件版，软件等价物先立起来：操作按可逆性分类，不可逆
（发布/支付/删除/群发）进 confirm 态——挂起、推送等确认、收到
确认再执行。与现有 shell_allow（事前白名单）互补：allow 管「能
不能用」，confirm 管「这次要不要人点头」。v1 软件闸门，真机上
对接物理键（见 DEVICE.md 硬件可偷清单）。

### 4. 主动性度量四件套 → 自动化质量指标

Violoop 用四个指标衡量「主动准备」是否真有价值：**采纳率 /
人工修改次数 / 重复任务完成时间 / 委托深度**。carrier 的
session-events（行为事实 JSONL）已有底子，给 cron/Push 自动化
补采这四项——防止「主动性」变成骚扰，也回答「cron 链是否真的
省了人时间」。

### 5. 成功率反馈闭环

路由分级的数据闭环：audit 记录每条路径成败 → 聚合出各路径实测
成功率 → 反哺首选路径选择。他们的「每天 1 万屏回归」是我们
validator 体系的等价物——flow validator 确定性闸门已经做了「结果
对不对」，补上「路径快不快稳不稳」这一维。

## 硬件侧可偷（详见 [DEVICE.md](DEVICE.md)）

- **确认键直连安全芯片的语义**：不可逆操作须物理按键，且按键是
  电气事件软件不可伪造——卡上 agent 键升级为此语义（v2 配安全
  芯片，v1 软件闸门先行）
- **「无电源键、插电即跑、24h 员工」的定位话术**：与我们
  「插电常驻+80% 限充」的形态假设一致

## 明确不学

| 他们的东西 | 为什么不学 |
|---|---|
| 寄生屏幕观察路线（HDMI 采集+Computer Use） | 哲学分岔，不是缺陷：我们赌 agent 有自己的手；看屏点鼠标是他们生态（Windows/macOS 长尾软件）的最优解，不是我们的 |
| 权重蒸馏个人化 | 做不起也不是我们的进化层；我们的进化在 clone 知识/flow/validator 层，是显式数据不是黑盒参数 |
| 26 TOPS / 53 tok/s 宣称 | RK3576 NPU 标称 6 TOPS，数字口径存疑（外挂加速器或激进测试条件）；但即便打折也提示本地小模型上限比我们保守估计高——Qwen 兜底是好消息 |
| 护城河叙事（学习系统/评价机制） | 概念上我们对应物已建成大半（flow/validator/dup/self-heal）；不焦虑，但记住他们把「评价机制」当护城河——validator 体系的价值要持续加码 |

（自己的手 vs 人的接口）和一张可以直接抄的工程清单——上面五条，
